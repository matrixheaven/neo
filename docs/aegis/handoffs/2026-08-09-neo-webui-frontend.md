## 2. 你的唯一职责

实现 `crates/neo-webui/web/` 下的 TypeScript、React、样式、前端测试和前端构建配置。网页在生产环境必须是本地打包资源，不能在运行时加载第三方脚本、字体、图片、样式或图标。

允许修改：

```text
crates/neo-webui/web/**
```

允许在该目录内新增构建配置、依赖清单、测试、固定接口样本和静态图标资源。

禁止修改：

- 所有 Rust 文件、Cargo 配置、命令行解析、监听、鉴权、会话调度、网页协议和测试。
- `neo-agent-core`、`neo-agent`、`neo-tui`、旧 RPC 和会话 JSONL。
- `docs/aegis/specs/2026-08-09-neo-webui-design.md`。
- 后端提供的协议样本字段、名称、状态或事件顺序。

发现网页协议不足时，停止实现并向协调者报告缺少的字段、用户场景和最小补充；不得自行添加字段、伪造状态或修改后端。

## 3. 固定数据边界

- 只通过后端的 `bootstrap`、会话摘要、会话快照、普通请求和网页长连接消费数据。
- 不读取会话文件、不调用旧 RPC、不调用模型、不执行工具、不推断文件路径。
- 当前会话的完整转录来自原样 `AgentEvent`；非当前会话只保留摘要和状态。
- 任务清单只从 `TodoUpdated` 投影。前端只能展开、收起、显示，不能改变任务状态。
- 工具完整输出只使用服务端提供的不透明输出引用和分页范围。
- 令牌只在首屏兑换期间保存在内存变量；兑换后立即清除地址片段，不写入本地存储、会话存储、日志或错误上报。
- 本地存储只允许保存左栏宽度等无敏感界面偏好。

## 4. 必须复现的视觉构图

整体是深色、克制、面向持续工作的界面，不是营销页，也不是卡片仪表盘。

### 顶部

- 高度 `48px`，左侧为工作区路径、当前会话和运行摘要。
- 右侧是改动入口和分支状态，不得展示模型、权限或开发模式。
- 有改动时，顶部下方显示细变更条：文件路径、增加行、删除行；点击后打开覆盖式改动视图，不挤压聊天区。

### 左栏

- 默认 `280px`，最小 `224px`，最大 `420px`；支持拖拽和键盘调整。
- 顶部是 Neo、折叠入口、新会话和标题搜索。
- 会话按置顶、普通、归档组织；当前会话使用低调选中背景。
- 悬停显示置顶和归档图标；右键菜单包含重命名、置顶或取消置顶、归档或取消归档。
- 不做网页删除会话操作。

### 主区

- 聊天画布占主区绝大部分面积。正文不使用大卡片，工具、审批和子代理只在交互需要时使用容器边界。
- 新会话显示 Neo 标识和同一个输入框，位置在视觉中心偏下。
- 首条消息后输入框移动到主区底部上方 `16px`，宽度为 `min(760px, 主区宽度减 48px)`。
- 输入框是半透明圆角矩形，约 `24px` 圆角，轻微背景模糊、细边框、低阴影；没有横线分隔、没有渐变。
- 输入框内部上半部分自动增高，最小 `52px`、最大 `180px`；下半部分从左到右放附件、逐条确认、开发模式，从右到左放运行状态、模型与推理、圆形发送。
- 任务清单悬浮在输入框正上方、同宽；收起时展示任务进度与当前进行项，展开时向上展开。没有任务则隐藏。
- 新消息提示悬浮在任务清单或输入框上方，不改变二者位置。

## 5. 转录状态机

必须按事件标识原位更新，不能把每个增量变成独立消息，也不能按视觉猜测状态。

1. 用户消息：右侧气泡。
2. 助手正文：左侧自由文本，代码块可复制。
3. 思考：默认折叠，进行中显示状态，展开后保留原始顺序。
4. 工具与终端：紧凑摘要行；展开后显示参数、命令、结果、耗时、排队位置与真实截断标记。
5. 审批与提问：转录内原位等待，处理后更新原条目。
6. 子代理：保留 Neo 的现有层级、展开和内容，不替换成通用任务卡。
7. 重试：由后端事件明确指示；撤去临时输出时必须同步删除对应尝试，不能把失败文本留在最终转录中。

用户手动离开底部后，新的流式内容只增加“返回最新内容”操作，不能抢走滚动位置。

## 6. 交互要求

- `Enter` 发送，`Shift+Enter` 换行；中文输入法组合态不发送。
- 回合运行时，普通发送为后续输入；立即引导和取消为不同操作，不得混淆。
- 会话切换只改变当前查看对象；不得关闭网页长连接、取消请求或清空后台会话状态。
- 归档运行中的会话后，它仍应显示运行状态。
- 右键菜单必须支持键盘菜单键或 `Shift+F10`。
- 分隔条、菜单、折叠条、审批、提问、发送、取消和回到最新内容操作均可键盘访问。
- 小于约 `980px` 时左栏改抽屉；小于约 `720px` 时为单列聊天界面。

## 7. 禁止事项

- 不做顶部设置条、底部固定横线输入栏、营销首屏、卡片瀑布流或装饰性渐变。
- 不使用外部网络资源、远程字体、第三方分析、遥测或 CDN。
- 不在浏览器中缓存全量后台会话转录、工具输出或令牌。
- 不新增本地任务清单、会话数据库、消息历史或静默重试。
- 不重命名或简化 Delegate、DelegateGroup、DelegateSwarm。
- 不用正则表达式猜测工具、思考、审批或事件状态。

## 8. 验收与交付

在后端固定样本可用时，至少验证：

1. 桌面宽屏、窄屏和手机宽度的截图中没有重叠、截断或空白主区。
2. 左栏拖拽、悬停置顶归档、右键菜单、键盘菜单和归档视图可用。
3. 新会话输入框居中，首条消息后变为半透明悬浮输入框。
4. 任务清单在输入框上方展开与收起，且不遮住最新消息。
5. 思考、排队工具、终端、审批、提问、子代理和重试样本按指定语义呈现。
6. 切换正在运行的两个会话时，背景状态持续更新且当前视图不重复事件。

使用浏览器自动化保留桌面和窄屏截图。交付时只报告：修改文件、使用的固定样本、验证命令和未解决阻断；不要自行提交。
