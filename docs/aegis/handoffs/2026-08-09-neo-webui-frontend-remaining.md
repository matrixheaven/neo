## 3. 固定前后端共识

### 3.1 打包资源

使用 Vite、React、TypeScript 和本地 CSS。依赖必须锁定在 `package-lock.json`，所有图标随 JavaScript 一并打包；推荐本地打包 `lucide-react`，不要手画常见图标。

生产构建必须只产生下列受控文件，并将它们提交为源码的一部分：

```text
crates/neo-webui/web/dist/index.html
crates/neo-webui/web/dist/assets/neo-webui.js
crates/neo-webui/web/dist/assets/neo-webui.css
```

Vite 配置必须关闭 source map、关闭动态导入和代码分包，并固定上述文件名。不要生成哈希文件名、运行时清单、外部字体、远程图片、第三方脚本、遥测、分析或 CDN 请求。后端会只用编译期 `include_bytes!` 嵌入这三个允许文件；任何额外资源都必须先由协调者明确加入允许列表。

`dist` 是交付物，不是本机缓存。构建后必须同时确认已跟踪资源没有变化，也没有未跟踪的额外资源。

### 3.2 认证与同源请求

页面启动时只做以下一次令牌处理：

1. 从 `location.hash` 读取 `access`，存入函数局部变量。
2. 调用 `POST /api/auth/claim`，请求体只有 `{"token":"..."}`。
3. 成功后立即调用 `history.replaceState` 清除地址片段，再开始读取 `bootstrap`。
4. 令牌缺失、已兑换、过期或认证失败时，只显示非敏感的重新打开提示；不得在错误对象、控制台、存储、页面文本、截图名称或遥测中回显令牌。

认证 Cookie 由浏览器自动携带。不得读写 Cookie，不得添加自定义认证头，不得把令牌放在长连接子协议中。所有请求使用相对路径和同源 WebSocket 地址。

本地存储只允许保存左栏宽度；不保存令牌、Cookie、完整转录、工具输出、草稿以外的会话状态、审批、提问、事件游标或任务清单。

### 3.3 最终实时线形

后端完成后，浏览器只消费强类型的最终网页消息：

- 工作区快照和 `session_summary_changed`：只含会话摘要，供左栏更新。
- 当前会话快照、`session_event`、`session_state`、`session_metadata_changed`：当前会话才接收完整转录。
- 每个当前会话事件和快照历史项都可能带一个可选的 `output` 元数据；其中 `id` 是读取工具输出的唯一不透明参数。

同一网页连接既订阅工作区摘要，也订阅一个当前会话。切换会话只替换“完整转录”订阅，不能关闭工作区摘要订阅，不能发送取消，不能清空其他会话摘要，不能停止后台回合。

每个游标必须按各自的 `stream_id + sequence` 去重。服务端要求快照、服务启动标识改变、慢连接以 `1013` 关闭或序列发生缺口时，清空该派生视图后只用服务端快照重建；不要尝试补造事件或继续使用旧游标。

### 3.4 请求行为

后端最终接口遵循原设计路径，具体字段以最终 `protocol.rs` 和样本为准：

- 新会话：`POST /api/sessions`，非空 `message` 与可选 `composer`。
- 空闲会话的新回合：`POST /api/sessions/<session_id>/turns`，同样必须携带非空 `message`。
- 活跃会话的普通输入：`POST /input`，`delivery: "follow_up"`。
- 立即引导：同一路径，`delivery: "steer"`，只有后端明确提供该能力时才显示独立操作。
- 取消、审批、提问：必须携带当前 `turn_id` 和对应请求标识。收到 `409` 时保留草稿并刷新快照，绝不假装成功。
- 元数据：`PATCH /api/sessions/<session_id>`，只发送用户实际更改的 `title`、`pinned`、`archived`。
- 工具输出：只把事件 `output.id` 作为 `<output_ref>` 传入读取路径，绝不编码、解码、拼接或猜测引用。

网页创建或启动回合后，不能把响应中的序号当作已取得完整转录的水位。先取得该会话的快照，再以快照水位订阅或续接，避免首个用户消息和早期事件丢失。用户消息只在规范 `MessageAppended` 到达后成为转录条目；发送请求期间可显示局部“发送中”状态，但不能制造永久的乐观消息或按文本内容去重。

## 4. 前端状态持有位置

状态必须按会话分片，不能使用一个全局 `isStreaming` 或一个全局转录数组。

```text
AppShell
  selected_session_id
  sidebar_width
  sidebar_drawer_open
  active_context_menu
  workspace_summaries
  workspace_cursor

SessionView[session_id]
  transcript_projection
  transcript_cursor
  phase / waiting_approval / waiting_question / turn_id
  pending_approval / pending_question
  latest_todos
  draft
  expanded_item_ids
  is_at_bottom / scroll_anchor
  reconnect_state
```

`transcript_projection` 是从快照和事件可重建的展示状态，不是第二份会话记录。当前会话以外绝不缓存完整转录、工具输出或思考文本。切换会话不删除其草稿、展开状态或滚动锚点，但这些状态仅驻留当前标签页内存。

实现一个纯 reducer，并用固定样本驱动它：

1. 收到会话快照时先清空目标会话的派生转录、待处理项、任务和游标，再按历史、等待项、任务、水位重建。
2. 收到序号不大于该会话水位的事件直接忽略。
3. `MessageStarted`、`TextDelta`、`MessageFinished` 按稳定消息标识原位更新；增量绝不成为独立气泡。
4. `ThinkingStarted`、`ThinkingDelta`、`ThinkingFinished` 按当前思考块原位更新，默认折叠。
5. 工具、终端、工作流、审批、提问、任务和 Delegate 系列只根据明确事件标签与标识更新；不得用文本、名称模式或正则推测状态。
6. `RetryScheduled`、`RetryResumed`、`RetryExhausted` 按服务端明确的尝试边界撤去临时输出。重连后的快照是最终裁决，不能保留失败尝试文本。
7. 不认识的新事件标签时保留一个可折叠的安全原始 JSON 记录，不抛异常、不丢掉后续事件、不把它解释为成功、失败或工具输出。

工具输出、命令输出和 Markdown 都视为不可信文本。不得使用 `dangerouslySetInnerHTML`、原始 HTML、脚本 URL 或内嵌框架；代码和输出用文本节点或 `<pre><code>` 呈现。Markdown 渲染只能使用关闭原始 HTML 的受控渲染器，链接必须拒绝非 `http`、`https` 协议。

## 5. 界面实施任务

### 任务 F1：建立可嵌入的本地应用

创建 `package.json`、锁文件、`tsconfig.json`、`vite.config.ts`、`index.html`、`src/main.tsx`、`src/app.tsx`、`src/api.ts`、`src/protocol.ts`、`src/state/**`、`src/components/**`、`src/styles.css` 与测试文件。

`api.ts` 只封装相对路径请求、固定 JSON 请求头、错误码和 WebSocket 收发。它不得知道文件系统、模型密钥、会话 JSONL 或旧 RPC。`protocol.ts` 只镜像最终 `neo-webui` 协议和固定样本，不从自由文本推导字段。

测试用的模拟请求和模拟网页长连接只能存在于测试目录或构建时排除的开发入口；生产 `index.html` 不得包含样本开关、测试数据或绕过认证的后门。

### 任务 F2：实现主工作区构图

页面是深色、克制、连续工作的操作界面，不是营销页，也不是卡片仪表盘。

- 顶栏固定 `48px`。左侧只显示工作区标签、当前会话摘要和运行状态；右侧只显示后端提供的改动入口与分支状态。绝不在顶栏放模型、逐条确认或开发模式。
- 左栏默认 `280px`，最小 `224px`，最大 `420px`。使用可拖拽分隔条和键盘左右键；宽度稳定，拖动不会推挤主区成不可用宽度。
- 会话列表按已置顶、普通、归档分组。悬停显示图标按钮用于置顶和归档；右键、菜单键、`Shift+F10` 打开同一菜单，包含重命名、置顶或取消置顶、归档或取消归档。点击悬停按钮或菜单不得切换当前会话。
- 搜索只请求后端标题搜索；不扫描转录、不建立浏览器全文索引。
- 小于约 `980px` 时左栏变为抽屉；小于约 `720px` 时为单列聊天界面。所有文字必须换行或截断，不得遮挡按钮、转录或输入框。

后端尚未提供结构化改动数据时，不显示空的改动入口或假统计。后端交付工作区改动接口后，顶栏入口打开右侧覆盖层，不压缩聊天画布；覆盖层只渲染后端给出的相对路径、增加删除统计和受限预览。

### 任务 F3：实现转录和滚动

- 用户消息靠右；助手正文靠左且不套大卡片；代码块提供图标复制按钮与提示。
- 思考、工具、终端、工作流使用紧凑折叠条。摘要行显示真实运行状态、名称、耗时、排队位置和服务端给出的截断状态；展开后显示参数、命令、结果和可读取的完整输出。
- `ToolExecutionQueued`、`ShellCommandQueued` 与对应更新必须显示“排队等待”，不能显示为已完成或超时。
- 审批和提问留在转录原位。提交一次后禁用本地按钮，等待服务端状态或快照确认；过期响应恢复可编辑状态并刷新快照。
- Delegate 与 DelegateSwarm 使用后端快照给出的层级、子项和进度。不要把它们改写成普通工具卡，也不要把不存在的 DelegateGroup 事件伪造为另一种结构。
- 用户主动离开底部后，新事件不得强制滚动；只在悬浮输入框或任务清单上方显示“回到最新内容”图标操作。回到底部后恢复跟随。

### 任务 F4：实现悬浮输入与任务清单

新会话只显示 Neo 标识和同一个输入框，置于主区视觉中心偏下。第一条规范用户消息出现后，输入框移至主区底部上方 `16px`，宽度为 `min(760px, 主区宽度减 48px)`；手机宽度为主区减 `16px`。

输入框是半透明圆角矩形，约 `24px` 圆角，轻微背景模糊、细边框和低阴影。不得做底部横线、固定页脚、渐变背景或分离工具栏。文本区最小 `52px`、最大 `180px`；超出上限后只有文本区滚动。圆形上箭头发送按钮固定在容器右下方，运行时改为明确的停止图标按钮。

`Enter` 发送、`Shift+Enter` 换行、中文输入法组合态不发送。新会话发送走创建接口，空闲会话发送走新回合接口，运行会话普通发送走 `follow_up`。停止与立即引导必须是独立且可辨识的动作，不能借用普通发送。

输入框工具行左侧仅在后端提供能力时显示逐条确认、开发模式、模型与推理选择；附件入口在没有上传接口时不显示。模型、逐条确认和开发模式只属于当前会话下一回合，不能写回全局设置。

最近 `TodoUpdated` 投影为与输入框同宽的悬浮任务清单，锚定在正上方，展开时向上生长。收起时显示完成进度与当前进行项；没有任务时完全隐藏；不可编辑。任务清单、输入框和“回到最新内容”必须留出转录底部空间，不能遮住最后一条内容。

### 任务 F5：无障碍与错误状态

分隔条、菜单、折叠条、发送、停止、审批、提问、复制和回到最新内容都需要键盘焦点、可见焦点样式、名称与辅助说明。状态不能只依赖颜色。右键菜单关闭时把焦点还给触发会话行。

`401` 显示无敏感的访问失效状态；`409` 保留用户草稿并刷新对应会话；`413` 提示输入过大；`1013` 断开后用无游标快照重连；普通网络失败使用有限退避，页面卸载和会话切换都不得发送取消请求。重连期间不生成第二个 WebSocket 的当前会话订阅。

## 6. 固定样本与测试

先用 `crates/neo-webui/fixtures/webui-events.json` 写纯 reducer 测试，再进行浏览器验收。现有样本已经覆盖两个会话、快照水位、续接、服务标识替换、思考、排队工具、审批、提问、重试撤回、任务、终端输出、工作流和慢连接样本；后端必须补入用户消息、DelegateSwarm、完整工具生命周期和不透明输出引用后，前端必须更新测试而不是自己拼造事件。

至少覆盖：

1. 地址片段只被兑换一次，并在成功后由 `history.replaceState` 清除。
2. 两个会话切换时，前一个后台摘要仍更新，完整转录只保留在当前会话。
3. 快照、水位续接、重复序号、服务标识变化和 `1013` 关闭都产生正确重建，无重复、无漏项、无失败尝试残留。
4. 思考、工具、终端、审批、提问、任务、Delegate、DelegateSwarm、工作流与用户消息按稳定标识原位更新。
5. 置顶、归档、重命名、悬停、右键、键盘菜单、分隔条、抽屉和手机单列可用。
6. 新会话输入框居中；已有对话为悬浮半透明输入框；任务清单位于其上方；没有底部横线输入栏和顶部模型权限模式。

使用真实浏览器自动化保留至少六张截图：宽屏新会话、宽屏运行会话和展开任务清单、窄桌面抽屉、手机单列、思考工具展开、右键菜单。静态样本截图可以使用仅测试用途的模拟服务；真实同源截图必须等后端静态资源嵌入完成。


## 7. 明确禁止与停止条件

- 不显示提供方密钥、原始配置、全局会话索引、会话目录、绝对路径或后端未提供的改动内容。
- 不读取文件、不运行工具、不调用模型、不发送旧 RPC 请求、不在浏览器中建立会话数据库。
- 不以 `useEffect` 清理、会话切换、归档、抽屉关闭或网页长连接断开取消后台回合。
- 不保留对当前不完整协议的兼容解析；最终协议落地后删除任何临时测试适配器。
- 不做顶部模型权限模式条、底部横线输入栏、营销首屏、卡片瀑布流、装饰渐变或文本按钮替代常见图标动作。

遇到以下任一情况立即停止并报告：后端要求前端解码输出引用；要求前端解析会话文件或路径；要用文本匹配判断事件；要将完整后台会话转录放进浏览器缓存；要跨来源连接真实服务；或需要修改 `web/**` 以外文件。
