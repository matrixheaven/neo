# Thinking and Message Presentation - Reflection

The design keeps the existing `ThinkingKind` path and adds only the missing
orthogonal message-phase concept. The summary-body bug is assigned to the
existing thinking renderer, while provider meaning stays in provider adapters
and ordinary message phase stays in normalized events. This avoids a renderer
heuristic that would lose body text or confuse commentary with the final
answer.

all unrelated user changes untouched and stages only the new Aegis records.
