# Neo v0.1.2

> Release channel: Stable
>
> Tag: `v0.1.2`
>
> Date: 2026-08-02 (UTC)

Neo v0.1.2 is the second stable release in the v0.1.1 line. It builds on
`v0.1.1` with the complete workflow platform, a redesigned workflow CLI and
task-browser operator, native terminal transcript presentation, and a large
reliability/CI hardening pass — 244 commits across 47 features and 116 fixes.

The headline of this release is the **workflow platform**: Neo can now define,
validate, run, control, and review durable multi-agent workflows entirely
locally, with builtin code-review, deep-research, and large-refactor templates,
journal-backed execution that survives crashes and resume, and a typed operator
surface for answering, pausing, saving, and stopping running workflows.

## Highlights

- **Workflow platform**: trusted definition registry, journal v3 runtime with
  replay/rehydration, heterogeneous swarms, durable user input, schema repair,
  artifact-backed final results, global resource admission, and verified linked
  runs.
- **Builtin workflows**: `code-review`, `deep-research`, and `large-refactor`
  ship with the binary and validate through the same public registry as
  user-authored definitions.
- **Redesigned workflow CLI**: exactly four commands (`workflow list/run/check/test`)
  with stable `--json` output, no durable runs from read-only checks, and
  plain-language list/help text.
- **Task-browser workflow operator**: answer forms driven by the answer schema,
  pause/resume/stop controls, contextual save of inline (unsaved) workflows,
  paged child browsing, and retention collection.
- **Assistant-native workflow tool**: `Workflow` is a first-class builtin tool
  routed through normal permission checks; slash entries (`/workflow:name`) and
  `create-workflow` skill authoring go through the same canonical path.
- **Native terminal transcript**: progressive native scrollback with live/history
  partitioning, blocking transcript focus preservation, streaming delegate
  activity, and workflow activity presented as one dynamic group.
- **Context budget work**: snip/dedup of stale tool results in request
  projection (occupancy-band gated, default off), default Read window of 400
  lines, and reliable session-title generation for reasoning models.
- **AI layer**: JSON Schema response formats, explicit reasoning disable for
  background requests, unified Anthropic tool-call assembly, bounded catalog
  responses, and structurally classified MCP/OAuth failures.
- **CI green**: formatting, clippy `-D clippy::all`, build, and the full
  `cargo nextest run --workspace --all-features` suite all pass; release assets
  cover six platforms.

## Added

- Workflow definition registry with user/project/builtin scopes, typed
  revisions, trusted resolution, no-clobber save, and effective-scope listing.
- Versioned journal scanning (v3 child lifecycle, direct and swarm children
  journaled uniformly) with torn-tail recovery and transactional lifecycle
  transitions.
- Durable user input (`await_user` / `TaskAnswer`) with schema validation,
  human/model answer policies, and journal-persisted request history.
- Heterogeneous swarm support, bounded child schema repair, strict Lua result
  contracts, child isolation and ceilings, and global resource admission.
- Artifact-backed canonical final results with content-addressed storage,
  bounded TaskOutput pages (summary / journal / result / artifacts), and
  page-budget shrinking to fit tool-result caps.
- Workflow retention: trigger constants, collection hooks, and watermark
  handling for completed runs.
- Builtin `create-workflow` skill and the `Workflow` tool adapter; skill
  activation now requires isolated calls.
- Paged workflow dashboard and operator state projection in the task browser.
- JSON Schema `response_format` support in `neo-ai`.
- Explicit `disable_reasoning` option for background requests (session titles
  and other fast, deterministic calls).
- Read tool snip geometry, snip/dedup projection plan fields, and
  occupancy-band snip activation config.

## Changed

- Workflow CLI redesigned to four exact commands; deleted retired CLI commands,
  flags, and the synthetic runner.
- Workflow actions (answer/pause/resume/stop/save) now route through normal
  permission decisions and canonical owner handles instead of ad-hoc plumbing.
- RunWorkflow executes through the assistant-native path; capability
  authorization plumbing and child launch indirection were removed.
- Model-visible workflow results now expose bounded, typed action outcomes;
  oversized turns are rejected before persistence and runtime context capacity
  is accounted for.
- TaskOutput content is JSON-serialized (stable envelope with details); summary
  views no longer embed full journals.
- Transcript presentation moved to progressive native scrollback: live entries
  are bounded, blocking entries own focus, and workflow activity renders as one
  dynamic group while ordinary transcript stays on the normal screen.
- Builtin tool schemas grew (26 tools), which is reflected in updated context
  budget tests and compaction trigger expectations.
- Provider model catalog refreshed; catalog responses are bounded and
  classified, and duplicate catalog fetches are avoided.

## Fixed

- Workflow: fail-closed on required child errors, preserved failed child
  semantics, constrained child model responses, recovered torn journal tails,
  supervised worker panics, isolated rehydration failures, drained completed
  channels, and preserved live workflow events/approval sources.
- Workflow: exposed action results to models with explicit inputs, bounded task
  output pages, reliable structured child results, and final/child
  `output_schema` enforcement on production paths.
- TUI: kept blocking transcript focus, capped completed delegate tool rows,
  spaced streaming thinking blocks, restored compact swarm terminal history,
  kept delegate child history grouped, and preserved workflow transcript
  history and provenance.
- Agent: reliable session-title generation for reasoning models, default Read
  window 400 lines with targeted-read guidance, robust snip newline handling,
  and preserved launch workspace when resuming sessions.
- AI: unified Anthropic tool-call assembly, finished started tool calls before
  `MissingName` on `finish_all`, omitted unsupported structured-output hints,
  hardened provider credential resolution, and stopped rewriting non-auth OAuth
  failures as `NeedsAuth`.
- Cross-platform: completed native Windows path prefixes, failed Windows entry
  when input mode is unknown, base64 notification encoding, and bounded
  clipboard helper execution.
- CI: cleared `clippy::all` failures, removed complexity lint exemptions,
  matched remote rustfmt output, removed warning-producing cache steps, upgraded
  the checkout runtime, and relaxed the slow-timeout for the 10k-row journal
  pagination test.

## Security and Safety

- Workflow child runs are isolated with explicit ceilings; oversized turns are
  rejected before persistence.
- Edit/Write prepared batches use single-file calls with fresh read context and
  bounded mismatch snapshots; automatic mismatch readback was removed.
- Shell timeouts are clamped; clipboard helper execution is bounded.
- MCP authentication is classified structurally; OAuth reconnect discovery is
  awaited before continuing.
- TaskOutput and workflow results are byte-capped to tool-result limits at every
  view boundary.
